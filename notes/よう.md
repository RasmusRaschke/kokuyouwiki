# よう（がない）

- V連用形 + よう + (がない)
- Without the negative, it expresses simply the manner of doing something.
- More often, it is used with 〜がない, expressing that there is no way of doing something.

**Examples**
1. この論文は直しようがない。
2. こんなに学生は人造知能を使っては教えようがない。
3. 他にやりようはないのだろうか。


# ようになる

- V連体形・V終止形ない + ようになる・ようになっている
- Expresses that some change happened, usually gradually, until the current point is reached.
- However, it can also be used with sudden changes in the affirmative.

**Examples**
1. ケインさんはドイツ語が話せるようになった。
2. この通りは今通れないようになっている。
3. 彼女は僕と一緒に時間を過ごさないようになった。

# ようにする

- V連体形・V終止形ない + ようにする・ようにしている
- Expresses that someone makes sure or spends some effort so that some change takes place.
- In the continuative form, the act of making sure that something takes place is habitual.

**Examples**
1. 毎朝七時に起こるようにしてください。
2. 毎日面打ちを千本するようにしている。
3. できるだけ日本語で書くようにしています。

# ように言う

- V連体形・V終止形ない + ように言う
- One function is to express the indirect imperative, stating that somebody ordered someone to do something. In this case, it occurs with controllable, volitional actions.
- With non-volitional verbs, it expresses how something is said.
- In the first case, 言う can be replaced by similar verbs like 頼む.

**Examples**
1. 母上は私に友達が来る前に部屋を掃除するように言った。
2. 俺は聞こえるようにはっきりいったんですが...
3. 碇司令はシンジくんにさっさとエヴァ一号機に入るように命じた。

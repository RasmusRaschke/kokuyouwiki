# に関して・に関する

- N + に関して・に関する〜
- Marks the topic of some occurrence or the regard to which something happens.

**Examples**
1. その学会で望月教授の発表に関して多くの批判がなされた。
2. 先週、京都で圏論に関する講演会を開催された。
3. その件に関しましては、まだ発表できる段階ではありません。

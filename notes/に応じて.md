# に応じて・に応じた

- N + に応じて〜・に応じたN
- In the first line, it expresses that the following is in response to the preceding, i.e., there is an actor responding to the preceding. However, this meaning is often broadened to include "according to" and "depending on", but usually still with an action done by an actor related to the preceding.
- The noun modification form に応じたN also expresses that N is suitable for the preceding.
- As opposed to によって, it cannot be used if there is no action to be done or no choice depending on something.

**Examples**
1. 組合の要求に応じて標準就業時間が短縮されることになった。
2. 天候や道路状況に応じた適当な運転を心がけましょう。
3. 髪のケアには欠かせないシャンプーには症状に応じて様々なタイプがある。

# 〜から〜にかけて

- 〜から + N + にかけて
- Expresses the range of something like [[まで#〜から〜まで]], but the noun preceding にかけて is a non-exact ending point. As such, it is not used when the end point is clearly specified.
- As opposed to [[わたる#にわたって・にわたる]], the structure often takes spacial and temporal markers as preceding clause and an occurrence as following clause.

**Examples**
1. 2023年の秋、七月から八月にかけて日本を旅行した。
2. 明日から明後日にかけて台風が上陸するので、海岸寄りの皆さんは警戒してください。
3. 低気圧が朝鮮半島から九州にかけて張り出しています。

# にかけては

- N + にかけては
- Marks a characteristic in which something or someone is proficient at or has a high level of confidence in.

**Examples**
1. フィールズ賞を拒否したグリゴリー・ペレルマンは数学にかけては他の数学者よりも優れた。
2. ラーメン作りにかけては王さんの右に出る人はいない。
3. 写真というものは絵画に比べて、その客観的再現力にかけては圧倒的に勝っている。

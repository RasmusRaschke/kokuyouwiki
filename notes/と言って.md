# といっても

- (~) + と言っても + ~
- Expresses that while the preceding is (technically) correct, the following is more appropriate and often less extreme / more specific.
- Often used with: [[だけ|ただ〜だけ]], [[ほど|（それ）ほど〜ない]], [[わけ|わけがない]]

**Examples**
1. 私には子供がいます。子供と言ってももう大学院生ですが。
2. もう三月だ。しかし、三月と言ってもこの辺はまだ寒い。
3. 仕事が見つかりました。と言ってもパートなんですが。

- The idiomatic expression (一口に) + N + と言っても expresses that N subsumes many specific things, which are then talked about.

**Example**
1. 一口に数学にいっても、圏論、分析学、代数学など様々な分類がある。

# からと言って

- ~連体形 + からと言って・からって + ~ない
- Expresses clearly that the speaker disapproves or disagrees with the following being caused by or done because of the preceding.

**Examples**
1. 子供だからといって許すわけにはいかない。
2. 期末試験に受からなかったからと言ってそんなに落ち込むことはない。
3. 自分の問題じゃないからと言って知らん顔をしているのはよくない。

# なんて

- ~ + なんて
- なんて is basically a contraction of several different particle constructions, always indicating some kind of strong emotion towards something. The different uses are:
	- It can act like [[なんか]] while the preceding need not be a noun.
	- It can act as quotation particle like なんという.
	- It can simply add emphasis like なんと〜んだろう and なんと, also acting as topicaliser.
- It also acts as informal variant of [[など]] while still being more emotional.

**Examples**
1. レポートのこと、社長はなんて言っていましたか。
2. なんていう人か名前を忘れたけれど、なかなか魅力的な女性に出会った。
3. あなたなんて最低よ。
4. 人間なんて脆いものなんでしょうね。

# 助数詞 + ほど

- 助数詞・指示詞 + ほど
- Expresses an approximate amount.

**Examples**
1. スミスさんは京都に四ヶ月ほど行っていました。
2. 旅は十時間ほどかかるでしょう。
3. あと一ヶ月ほどで夏休みになる。

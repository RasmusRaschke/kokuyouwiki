# 過ぎる

- V連用形・いA・なA + 過ぎる
- Expresses that something is excessive or done excessively.
- With 〜ない, there is a morphological shift to 〜なさ過ぎる.

**Examples**
1. このマンションは私達には高過ぎる。
2. 一年昔のあなたは、幸福すぎて、思いのままであり過ぎて、僕なんかには眩しいようでした。
3. 横綱は土俵にゆっくり入り過ぎた。

# に過ぎない

- V音便形{た・て}・いAだけ・なA{な・だった}だげ・N + に過ぎない
- Expresses that something does not exceed the preceding, either literally, e.g., if the preceding is a 助数詞, or figuratively.
- Rarely appears with adjectives.

**Examples**
- これは僕の私見にすぎない。
- あの女はただ言われたことをしているだけに過ぎない。
- 俺の収入はアルバイトを入れても年三万ドルに過ぎない。

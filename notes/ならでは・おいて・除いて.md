# ならでは

- N + ならでは
- Expresses that something is the only thing to which something applies or the only thing/one that can perform something.

**Examples**
1. 四季をと通じて美しい景色が楽しめるのはこの地ならではだ。
2. 君ならではできないことだよ。
3. この教科書ならではの特徴です。

# をおいて

- N + おいて
- Emphasises that to no other than the preceding something applies in a positive manner.

**Examples**
1. 君をおいて適任者はいないぞ。
2. これをおいて他に方法はなかった。
3. それはさておいて〜

# を除いて

- N + 除いて・除き
- States that the preceding is exempted from something.

**Examples**
1. 私は除いてください。
2. 北部を除いて、お天気は良かったですよ。
3. 私は報道記者を政治家を除く全ての人々が平等であると信じている。

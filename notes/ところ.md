# ところだ

- ~ + ところだ
- Represents a location which can be reached in some amount of time.
- Contraction of ところにある

**Example**
1. 俺のうちは学校から歩いて十五分のところだ。

- V連体形・いAいところ・なAな・Nの + ところ
- Marks the state in which an action just began (non-past) or has just been finished (past).
- If the preceding and the following are in the past, the meaning shifts to an action which was almost but not actually done.
- As opposed to the て-form, the focus is heavily on the state/scene, not the action.
- As opposed to [[ばかり]] in the temporal sense, たところ strongly implies that hardly any time has passed since the action was completed.

**Examples**
1. 愛好は朝ご飯を食べるところです。(temporal)
2. ３章まで読んだところで寝てしまった。(temporal)
3. 僕は危うく溺れるところだった。(subjunctive)
4. この写真は学生が野球をしているところです。(scene)
5. 彼女の理論は、仲間の調査によるところが大きい。(abstract place/point)


# たところ

- V音便形た + ところ
- Expresses that something results from an intentional action. The resulting cannot be an expression of volition or something controllable by the speaker.
- Slightly formal expression which is more restrictive, but similar to [[たら]].

**Examples**
1. 先生に相談したところ、是非大学院に行くように進められた。
2. これまでに書いた論文を本にしたところ、意外によく売れた。
3. 50代の男性にどこに旅行に行きたいか訊いたところ、沖縄が一位だった。

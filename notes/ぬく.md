# 抜きにしては・抜きには・抜きでは

- N + 抜きにしては・抜きには・抜きでは + 〜 + 否定
- Expresses that without the preceding noun, something is impossible.
- The noun should be something which is missing, i.e. something which would normally not be a problem.

**Examples**
1. 晩ごはん抜きでは、翌朝に全力が出せないよ。
2. ガロア理論抜きには、抽象代数学を教えられない。
3. あの話題は冗談抜きで重大だから無視しないほうがいい。

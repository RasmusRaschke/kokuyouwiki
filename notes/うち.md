# うちに

- V連体形・V音便形ている + うちに
- Expresses that the following happens while the preceding is still going on.
- When the verb before うちに is in the continuative form, it indicates that the action is very long compared to the following action. This is often seen with non-instantaneous verbs.
- Acceptable nouns are only ones expressing a duration, like 夏 or 昼間.

**Examples**
1. 前田さんはアメリカにいるうちに英語が上手なりました。
2. 若いうちに本を沢山読みなさい。
3. 知らないうちに、眠ってしまっていた。
4. 赤ちゃんが寝ているうちに、新聞を読んだ。

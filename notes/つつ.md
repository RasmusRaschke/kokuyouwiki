# つつある

- V連用形+つつある
- Expresses that some change is currently taking place gradually or about to be finished.
- Often used with gradual adverbs like 次第に・徐々に・だんだん・少しずつ

**Examples**
1. 政治に興味を持つ若者が次第に増えつつあるようだ。
2. 台風が九州接近しつつある。

- Never used with habitual actions
	- 図書館で勉強しつつある。-> wrong
	- 図書館で勉強している。-> correct


# つつ

- V連用形 + つつ
- Expresses that one agent performs two actions simultaneously.
- It tends not to be used with action verbs of everyday actions, but more often with verbs showing mental or abstract actions.
- The expression is more formal than [[ながら]].
- It can be used with *almost* instantaneous verbs, as example 3 shows.

**Examples**
1. 彼は最後まで自分の学説が正しいことを主張しつつこの世界を去った。
2. 悪いことと知りつつ、友達に嘘をついてしまった。
3. 出発しつつ、電車はスピードを上げていった。

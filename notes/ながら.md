# ながら

- V連用形 + ながら + ~
- Expresses that two actions are performed at the same time by the same agent. The preceding action must be secondary to the following action.
- It cannot be used with verbs expressing an instant occurrence such as 死ぬ or 座る. 
- As opposed to [[つつ]], it can be attached to nominal phrases, but if both conjunctions are permissible, the meaning is identical.

**Examples**
1. 歩きながらスマホを使うのは危ないですよ。
2. 大学に通いながら、月に60万円くらい稼いでいました。
3. 宿題しながらピザを食ってて気づいたらなくなっていた。

# ながら（も）

- V連用形・Aい・N(であり) + ながら(も)
- Disjunctive conjunction roughly equivalent to "although". The preceding is often a clause expressing the state or existence of something.
- も only adds emphasis.
- The conjunction is mainly used in written and formal language.

**Examples**
1. 田口はそのことを知りながらも黙っていた。
2. しかしながら、予算案はまだ修正の余地がある。
3. 日本の単身赴任のサラリーマンは苦しみながらも、会社のために働いている。

# ながらに（して）・ながらの

- V連用形・Aい・N + ながらに(して)・ながらのN
- Expresses that the preceding is or remains in some state while doing or having the following, translating to "while" or "as".
- The construction only accepts certain words as the preceding.

**Examples**
1. 人間には、生まれながらにして貧富の差がある。
2. 田中さんは家に居ながらにして、月に70万円くらいの収入を得ている。
3. この会社は昔ながらの製法で豆腐を作っている。

# もさることながら

- N + もさることながら
- Expresses that while the preceding is important, the following is more important.
- Formal expression

**Examples**
1. 中華料理は味もさることながら、健康にいいですよ。
2. 障害者向け製品の価格が高いのは、技術的な困難もさることながら市場の小ささが大きな原因になっている。
3. 下から眺めるテレビ塔やイルミネーション美しさもさることながら、展望台に登って眺める市の夜景もまた格別です。

# せい

- V*・Nの + せい + (P)
- Marks something as the cause bringing about an undesirable result unless せい occurs with か, in which case the result can also be desirable.
- Cannot be used to express reason.

**Examples**
1. 毎晩お酒をたくさん飲んでいたせいで肝硬変になっちゃった。
2. 足が折れたせいで運動が全然できない。
3. 薬を飲んでから気のせいか少し気分が良くなった。
